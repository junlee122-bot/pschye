# 아트 디렉션과 자산 검증

## 시각 언어

《라온제나》의 화면은 **서유럽 고딕 군사 기록물 + 낡은 전쟁화 + 현대 전술 인터페이스**의 결합을 목표로 한다.

- 색: 흑철, 젖은 돌, 상아색 종이, 오래된 금박, 응고된 적갈색
- 실루엣: 긴 코트, 판금 보강, 가문별 문장, 무기 중심의 비대칭 장비
- 조명: 흐린 자연광, 불씨, 총구 섬광, 금색 UI 포인트
- 질감: 양피지, 긁힌 금속, 비, 먹 번짐, 낡은 사진 가장자리
- 금지: 현대 스트리트웨어, 과한 네온, 가벼운 모바일 뽑기 UI, 인물의 상처를 장식으로만 소비하는 연출

## 제공 원화

`public/art/archive`에는 사용자가 제공한 20장의 설정화를 전부 보존한 자산이 있다. 기존 15장은 WebP로 최적화했고, 이번에 추가된 주요 인물 5장은 원본 PNG를 그대로 보존했다.

- 프시케 1~7기 단체 시트
- 라온·하도리·카즈린·카인·레오 사분면 캐릭터 시트
- 해찬·라미·진훤·마루·나비/니아 단독 캐릭터 시트
- 대전쟁 주요 인물의 과거/현재 시트
- 아카이브 표지와 제5기 초기 시트

원본 파일명과 현재 자산 경로는 `docs/source/asset-sources.json`에서 추적한다. 20장 모두 아카이브 필터·검색 결과에 노출되며, 데스크톱과 모바일에서 이미지 로드와 비율을 검증했다.

## 새로 제작한 원화

원화 공백은 기존 시트의 검은 잉크선, 낡은 종이, 서양식 의복과 무기 비례를 기준으로 새로 제작했다.

| 파일 | 목적 | 검증 항목 |
|---|---|---|
| `mission-grey-bridge.webp` | 첫 임무의 와이드 키아트 | 교각·마차·비·익인 위협이 읽히는지, UI 배경으로 명암 여유가 있는지 |
| `cheshi-sniper.webp` | 체시 저격수 적 카드 | 날개·장총·폐탑 실루엣이 작은 카드에서도 구분되는지 |
| `chris-sheet.webp` | 누락된 제7기 크리스 시트 | 기존 7기 시트와 의복 언어가 맞고, 리스트류 검술과 상인 가문 출신이 동시에 보이는지 |
| `generation-05-mending.webp` | 확정된 봉합의 5기 | 크라우드·캄프타·아델린·브리짓·아벨·모이라의 역할 실루엣이 겹치지 않는지 |
| `campaign-world-map.webp` | 장기 캠페인 전략 전역도 | 제국·폐도·저주받은 땅이 한 화면에서 구분되고 작전 노드를 얹을 여백이 있는지 |
| `mission-citizen-cartridge.webp` | 시티즌 지하 탄약 밀수 작전 | 서양식 주점, 구세계 탄피, 상단 음모가 한 장면에서 읽히는지 |
| `mission-empty-generation.webp` | 제3기 생존자 마을 방어 | 눈 덮인 재건촌과 장거리 저격의 불안이 동시에 보이는지 |
| `mission-wingless-convoy.webp` | 실험체·혼혈 국경 호송 | 다양한 생존자와 추격대, 절벽길 호송 방향이 명확한지 |
| `mission-sky-gunfire-v2.webp` | 체시 공중 요새 강습 | 비행 요새·공중 포대·제7기 돌입 방향이 한 화면에서 읽히는지 |
| `mission-violet-night-v2.webp` | 바이올렛 기록보관소 잠입 | 붉은 실 함정·감사관·잠입자의 깊이 관계와 어두운 UI 여백이 충분한지 |
| `mission-cursed-border-v2.webp` | 저주받은 경계 삼파전 | 제국·혼혈 생존자·체시 사수가 분리되고 민간인이 장면의 중심에 남는지 |
| `mission-stopped-petal-v2.webp` | 멈춘 꽃잎 대면전 | 지팡이를 짚은 해찬 실루엣·여섯 후계자·정지한 꽃잎의 감정 방향이 명확한지 |

열두 자산은 생성 뒤 원본 해상도와 1600×900 WebP 결과를 직접 확인했다. 신규 후반 작전 네 장은 색상 평균·해상도·용량 검증을 거쳐 프로젝트에 포함했다.

## 캐릭터 시트 기준

- 4분면 또는 다중 포즈: 전신, 얼굴 확대, 무기/손, 관계·생활 컷
- 최소 한 컷은 전투 외 행동을 담아 캐릭터를 직업 아이콘으로 축약하지 않는다.
- 중요한 1세대는 대전쟁 이전·전성기·현재의 세 시점을 구분한다.
- 영구 장애와 노화는 실루엣·보조구·전투 자세에 지속 반영한다.
- 해찬의 현재 모습에 시간 권능 효과를 추가하지 않는다.
- 나비/니아는 단순한 악한 자아/선한 자아 색상 분할로 처리하지 않는다.

## 다음 우선 제작 목록

1. 해찬 현재 보강 시트: 지팡이, 짧은 간격 싸움, 손상된 보법의 세부 동작
2. 라미 최종전 변형 시트: 매력적인 해방자와 멸종론자의 연속성
3. 가람 군단 단체 시트: 혼혈·사생아 집단의 종족 다양성
4. 아델린 단독 시트: 공명망의 감각 과부하와 소형 방패·단창
5. 제3기 참사 환경화: 체능 진형을 무너뜨린 장거리 총격
6. 해찬 대 라미 최종전 키아트: 권능 효과보다 순수 체능과 선택의 충돌을 강조

## UI 사용 원칙

- 원화를 카드에 억지로 잘라 넣지 않고 `object-position`을 인물별로 조정한다.
- 텍스트 대비를 위해 원화 위에는 비네트와 그라디언트를 사용하되 얼굴을 가리지 않는다.
- 아트 아카이브에서는 원본 비율을 유지하고 전체 화면 확대를 제공한다.
- 전투 화면에서는 키아트를 무대로 사용하고, 유닛 정보는 별도 전술 레이어에 배치한다.
- 생성 원화와 제공 원화의 출처를 폴더와 문서에서 명확히 분리한다.
