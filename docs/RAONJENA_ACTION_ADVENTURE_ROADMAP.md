# 라온제나: 스토리 중심 3D 액션 어드벤처 로드맵

## 목표 정의

목표는 ‘젤다를 복제한 MMO’가 아니다.

> **라온의 시점으로 살아가는 장편 스토리와, 플레이어가 스스로 발견하고 조합해 해결하는 3D 액션 어드벤처를 결합한다.**

현재 React/Phaser 게임은 버리지 않는다. 이 버전은 수백 장면의 분기, 관계도, 전투 규칙, 저장 데이터, 콘텐츠 검증을 빠르게 반복하는 **설계 실험실**로 유지한다. 실제 3D 이동과 전투는 Unity 6 URP 버티컬 슬라이스에서 새로 만든다.

## 왜 Unity 6 URP인가

- 현재 팀 규모와 Intel UHD 620 개발 장비에서는 Unreal 5의 고사양 오픈월드·MetaHuman 중심 제작보다 Unity URP가 반복 속도와 배포 범위에 유리하다.
- Unity AI Navigation은 런타임 NavMesh, 동적 장애물, 점프 연결을 제공한다. [Unity AI Navigation](https://docs.unity3d.com/ja/current/Manual/com.unity.ai.navigation.html)
- Addressables는 AssetBundle 위에서 주소 기반 비동기 로딩과 자산 관리를 자동화한다. 지역·던전·캐릭터 의상 스트리밍에 적합하다. [Unity Runtime Asset Management](https://docs.unity3d.com/ja/current/Manual/assets-managing-introduction.html)
- Unity LOD Group과 URP GPU Occlusion은 넓은 마을/폐허의 원거리 비용과 가려진 오브젝트 비용을 줄일 수 있다. [Unity LOD](https://docs.unity3d.com/es/current/Manual/LevelOfDetail.html), [Unity URP GPU Occlusion](https://docs.unity3d.com/cn/6000.0/Manual/urp/gpu-culling.html)

Unreal 5는 향후 전용 GPU와 3D/테크아트 인력이 확보되면 다시 평가한다. World Partition과 Data Layers는 대규모 스트리밍과 퀘스트별 월드 변형에 강력하다. [Unreal World Partition](https://dev.epicgames.com/documentation/unreal-engine/world-partition-in-unreal-engine), [Unreal Data Layers](https://dev.epicgames.com/documentation/unreal-engine/world-partition---data-layers-in-unreal-engine)

## 젤다형 설계에서 가져올 원칙

Nintendo 개발진은 능력 하나와 다양한 반응을 가진 세계를 **곱셈**해 플레이 경험을 확장한다고 설명한다. 사물은 복잡한 설명 없이도 익숙하게 보여야 하고, 정교한 해법과 단순한 해법이 모두 가능해야 한다. [Ask the Developer Part 4](https://www.nintendo.com/us/whatsnew/ask-the-developer-vol-9-the-legend-of-zelda-tears-of-the-kingdom-part-4/)

또한 지상·하늘·동굴의 수직 연결, 이미 알던 장소를 새 단서로 다시 보게 만드는 탐험, 지표에서 바로 이어지는 지역 고유 던전을 강조한다. [Ask the Developer Part 3](https://www.nintendo.com/us/whatsnew/ask-the-developer-vol-9-the-legend-of-zelda-tears-of-the-kingdom-part-3/)

라온제나에서는 이를 다음처럼 번역한다.

### 체능 × 환경

- **라온의 흐름:** 적 공격을 흘리고, 물레·문·바람길·낙하물을 연쇄 작동한다.
- **16꽃잎:** 전투기인 동시에 봉인 문양, 덩굴, 밧줄, 다중 표적을 정확한 순서로 끊는 탐험 기술이다.
- **이능 감각:** 전투 강화가 아니라 숨은 기맥, 거짓 기록, 잔류 감정을 읽는 조사 도구다.
- **동료 지시:** 하도리의 힘, 카즈린의 창, 레오의 방어를 ‘파티 스킬 버튼’이 아니라 환경 해법으로 사용한다.

각 장애물은 최소 세 가지 해법을 갖는다.

1. 순수 이동/관찰로 해결
2. 체능과 환경 조합으로 해결
3. 동료·관계·이전 선택으로 우회

## 첫 버티컬 슬라이스

### 범위

- 30~40분
- 라온 한 명만 직접 조작
- 첫 마을 1개, 연결 길 1개, 소형 폐허 던전 1개
- 전투 3회, 환경 퍼즐 3개, 주요 대화 6개, 의미 있는 선택 2개
- 마지막에 같은 마을로 돌아와 선택의 결과를 공간·NPC·음악으로 확인

### 진행

1. **라온의 집:** 걷기, 살펴보기, 물건 집기, 가족/마을 관계 소개
2. **첫 마을:** NPC 일과, 선택형 대화, 카즈린과의 약속, 카인의 도발
3. **바람 언덕길:** 점프, 매달리기, 짧은 등반, 낙하 공격
4. **폐허 수로:** 물 흐름과 검격을 이용한 다중 해법 퍼즐
5. **감시탑:** 체시 정찰병/실험체 미니보스, 16꽃잎의 불완전한 첫 발현
6. **귀환:** 구한 사람, 회수한 기록, 선택한 길에 따라 마을의 대사·상점·경계가 변함
7. **후크:** 프시케 입단 시험 제안

### 전투 핵심

- 약공격 연타가 아니라 **관찰 → 흘리기/회피 → 자세 붕괴 → 검로 완성**의 네 단계다.
- 적은 체력보다 자세, 의도, 거리, 환경 취약점을 가진다.
- 검격은 이동 도구이기도 하다. 공격 후 위치, 벽 반동, 낙하, 밧줄 절단이 전투 선택을 바꾼다.
- 한 전투는 30~90초, 일반 적은 2~4종의 읽을 수 있는 행동만 갖는다.

## 만들지 말아야 할 것

- 첫 단계부터 대륙 전체 심리스 오픈월드
- 48명 전원의 최종 리그와 20개 의상
- MMO 서버, 길드, 레이드, 경매장
- 수백 재료의 생존 제작 시스템
- 자동 생성 던전 100개
- 모든 표면을 오를 수 있는 범용 등반

이 기능들은 콘텐츠보다 기술 부채를 먼저 만든다. 첫 마을 한 곳에서 이동·전투·탐험·선택·귀환이 재미있다는 것을 증명한 뒤 확장한다.

## 90일 제작 순서

### 1~3주: 조작감 증명

- Unity 6 URP 프로젝트와 입력·카메라·이동
- 회색 박스 마을, 언덕, 폐허
- 라온 LOD0 마켓을 임시 리그로 연결
- 검술 3타, 회피, 흘리기, 자세 게이지

### 4~6주: 세계 반응

- 자르기/밀기/기맥 읽기 상호작용
- 적 2종, 미니보스 1종
- 퀘스트 상태와 마을 귀환 변화
- 첫 플레이테스트 30회

### 7~9주: 스토리와 캐릭터

- 대화 카메라, 라온·카즈린·카인 핵심 장면
- 라온 얼굴 리그와 핵심 표정 20개
- 마을 NPC 스케줄과 반응
- 접근성: 난이도, 카메라 흔들림, 자막, 입력 리맵

### 10~12주: 품질 게이트

- 라온 수동 리토폴로지/PBR/리그 교체
- LOD, Addressables, 메모리/프레임 프로파일
- 200경로 자동 상태 검사 + 50명 수동 플레이테스트
- 버티컬 슬라이스 패키징

## 현재 판정

`pnpm world:readiness`는 현재 웹 프로토타입이 가진 증거와 Unity 버티컬 슬라이스에서 비어 있는 핵심 시스템을 분리한다. 웹 버전은 스토리·선택·전투 규칙을 계속 검증하고, Unity 버전은 이동·환경 상호작용·3D 캐릭터 생동감에 집중한다.
