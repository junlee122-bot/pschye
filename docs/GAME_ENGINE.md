# 라온제나 게임 엔진 아키텍처

이 문서는 **웹 서사·전투 설계실**의 구조를 설명합니다. [액션 어드벤처 로드맵](RAONJENA_ACTION_ADVENTURE_ROADMAP.md)에 따른 3D 본편은 Unity 6 URP로 진행하며, 첫 기반은 `unity/PsycheAdventure`와 [3인칭 기반 문서](THIRD_PERSON_FOUNDATION.md)에 있습니다. 두 프로젝트의 저장 데이터는 아직 연동되지 않습니다.

## 목표

《라온제나》는 라온의 시점으로 진행되는 장편 스토리 RPG다. 탐색, 선택, 관계, 기록은 React UI가 담당하고 실제 전투는 Phaser가 담당한다. 플레이어는 별도의 장르로 이동하는 느낌 없이 이야기에서 전투로 진입하고, 전투 결과가 다시 라온의 기록과 관계 변화로 돌아오게 된다.

## 현재 구조

```text
React 19
├─ 라온 시점 캠페인과 선택
├─ 동료, 프시케, 세계관 기록
├─ 임무 편성, 난이도, 성장
└─ 전투 명령 콘솔
   └─ Phaser 3.90 전술 전장
      ├─ 유닛과 표적 입력
      ├─ 체력, 방벽, 피해 예고
      ├─ 집중 연계와 BREAK
      ├─ 카메라 흔들림과 타격 연출
      └─ React 전투 엔진과 이벤트 동기화
```

전투 규칙은 `src/game/battleEngine.ts`의 순수 상태 전이로 유지한다. Phaser는 상태를 직접 결정하지 않고 시각화와 포인터 입력만 담당한다. 따라서 전투 수치 테스트, 세이브 호환, 모바일 UI, 향후 다른 렌더러로의 교체가 가능하다.

## Unity 대신 Phaser를 우선한 이유

- 현재 게임의 강점인 장편 서사 UI와 기록 시스템을 그대로 유지한다.
- Unity WebGL 빌드의 초기 다운로드와 메모리 부담 없이 즉시 전투에 들어간다.
- Vercel 정적 배포와 기존 저장 데이터를 그대로 사용한다.
- React와 엔진 사이의 책임이 분리되어 전투 규칙을 자동 테스트할 수 있다.
- Phaser를 지연 로드해 타이틀과 스토리 화면의 첫 로딩을 막지 않는다.

이 선택은 웹 설계실에 적용합니다. 3D 필드 탐색·물리·캐릭터 조작을 담당할 Unity 본편의 기반 작업은 시작했으며, 웹은 기존 이야기·선택·전투 규칙의 검증에 계속 사용합니다.

## 조작

| 입력 | 기능 |
|---|---|
| 마우스·터치 | 조장 또는 적 선택 |
| `1`–`6` | 여섯 조장 즉시 선택 |
| `Q`, `W` | 선택 조장의 기술 전환 |
| `Tab` | 행동 가능한 다음 조장 |
| `Space` | 명령을 모두 사용한 뒤 적 턴 진행 |
| `R` | 추천 명령과 전술 콘솔 열기 |

화면 읽기 도구와 키보드 사용자를 위해 Phaser 캔버스 위에 동일한 조작을 제공하는 접근성 입력층을 둔다.

## 전투의 핵심 루프

1. 적 머리 위의 다음 행동과 피해 예고를 읽는다.
2. 보호, 노출, 공격 중 세 번의 명령을 고른다.
3. 서로 다른 조장으로 같은 적을 공격해 집중 연계를 쌓는다.
4. 세 번째 연계로 BREAK를 일으켜 적 행동을 취소한다.
5. 목표와 동료를 생존시킨 채 제한 라운드 안에 전장을 정리한다.

이 구조는 반사 신경보다 라온의 판단과 동료 이해를 보상한다. 각 조장은 단순한 속성 카드가 아니라 라온이 누구를 믿고 어떤 순서로 부탁할지를 결정하는 전술 자원이다.

## 확장 로드맵

### 1단계 — 전술 전장

- 영웅과 적의 엔진 렌더링
- 피해 숫자, 카메라 흔들림, 선택 링
- 집중 연계, BREAK, 적 의도 표시
- 키보드와 터치 조작

### 2단계 — 임무 다양화

- 호송, 구조, 방어, 추격, 잠입, 보스전 전용 승리 조건
- 지형 엄폐, 사선, 붕괴 구역, 함정 타일
- 라온의 선택에 따라 달라지는 전장 시작 상태
- 조장별 전투 대사와 관계 합동기

### 3단계 — 탐색과 성장

- 프시케 본부의 2D 탐색 허브
- 동료 훈련, 장비 제작, 기록 조사
- 임무 전 야영과 임무 후 보고서
- 선택에 따라 열리는 라온류 검술 노드

### 4단계 — 대규모 전쟁

- 제7기와 상위 기수가 함께 싸우는 다중 분대 전투
- 체시 총기, 반데닌 원소, 프시케 체능의 상성
- 전선 지도와 장기 작전 자원
- 해찬편에서 같은 전장을 1세대의 규칙으로 재해석

## 성능 원칙

- Phaser는 전투 진입 시에만 동적 import한다.
- 이미지 원본은 전투 해상도에 맞춘 WebP 파생본을 사용한다.
- 전투 상태는 React가 소유하고 Phaser Scene은 이벤트로 갱신한다.
- 장면 전환 시 Phaser 인스턴스와 이벤트를 반드시 파괴한다.
- 전투 규칙은 캔버스와 분리해 Vitest로 회귀 검증한다.
