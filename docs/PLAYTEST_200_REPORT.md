# 라온제나 전체판 200+ 플레이 감사 보고서

## 1. 검증 대상

- 대상: GitHub 저장소에 올릴 로컬 전체 소스 트리
- 경로: `work/pschye`
- 제외: Vercel에 별도로 올렸던 약식 빌드
- 실행일: 2026-07-24
- 브랜치: `main`
- 원격 저장소: `https://github.com/junlee122-bot/raonjena.git`

원격 저장소에는 아직 브랜치가 게시되어 있지 않아, 이번 검증은 원격 배포본이 아니라 GitHub에 게시할 전체 로컬 작업 트리를 기준으로 수행했다.

## 2. 방법

프로덕션 게임과 동일한 전투 엔진, 임무 데이터, 저장 프로필 성장, 장비 보정과 난이도 규칙을 사용해 240개의 완전한 캠페인 경로를 실행했다.

- 캠페인 플레이: 240회
- 캠페인당 임무: 8개
- 실제 전투 규칙 실행: 1,920회
- 플레이 성향: 추천 추종, 공격 우선, 방어 우선, 초심자 무작위
- 난이도: 이야기, 정규, 숙련
- 교차 조건: 라온의 성향, 교리, 전쟁 압박, 동료 신뢰, 장비 성장
- 원시 기록: `artifacts/playtest-200/final.json`
- 사람이 읽는 결과: `artifacts/playtest-200/final.md`

이는 240회를 손으로 같은 입력만 반복한 기록이 아니라, 실제 게임 엔진을 사용하는 결정론적 자동 플레이 감사다. 각 경로는 서로 다른 성향과 난이도 조합으로 8개 임무를 끝까지 진행한다.

## 3. 기준선 문제

초기 240회 감사에서 다음 문제가 확인됐다.

1. 전투 진입 직후 조작 방식이 설명 없이 결정됐다.
2. 숨은 적을 공격하면 왜 실패했는지 충분히 드러나지 않았다.
3. 추천 행동은 설명만 하고 실제 행동은 다시 눌러야 했다.
4. 행동력이 남은 상태의 턴 종료가 조용히 막혔다.
5. 액션 전투는 키보드 조작 안내와 모바일 이동 수단이 부족했다.
6. 숙련 난이도 승률이 27.5%로 지나치게 낮았다.
7. 추천 추종 플레이도 일부 임무에서 방어 행동을 반복하다 패배했다.

## 4. 적용한 개선

### 전투 진입

- 전투마다 `라온 직접 조작`과 `제7기 전술 지휘`를 먼저 선택하도록 변경
- 터치 기기에서는 전술 지휘를 추천
- 액션 전투 시작 전 조작 안내 모달 추가
- 직접 조작 중 전술 지휘로 전환 가능

### 전술 전투

- 추천 버튼을 `추천 즉시 실행`으로 변경
- `R` 키로 추천 행동 즉시 실행
- 숨은 표적을 잘못 누르면 크리스가 행동 가능한 경우 자동 개시
- 자동 개시가 불가능하면 엔진에 무효 입력을 보내지 않고 즉시 이유 표시
- 행동력이 남은 턴 종료 시도에 명확한 피드백 표시
- 목표가 실제로 붕괴 직전일 때만 방어를 추천
- 처치 가능한 적과 기대 피해가 높은 공격을 우선하도록 추천 로직 보강

### 액션 전투

- `WASD`, 회피, 기본 공격, 해찬류, 동료 명령을 시작 전에 설명
- 모바일 포인터 입력용 방향 패드 추가
- 첫 적 공격을 늦춰 학습 시간을 확보
- 전술 전투로 돌아가는 경로를 항상 노출

### 난이도

- 숙련 난이도의 적 체력·피해·목표 내구를 재조정
- 불합리한 즉사 압박은 낮추되, 정규 난이도보다 높은 전술 요구는 유지

### 로딩과 번들

- React와 아이콘 묶음을 분리
- Phaser는 직접 조작 또는 마을 장면에 들어갈 때만 지연 로드
- 초기 메인 JavaScript를 약 637KB에서 약 412KB로 축소

## 5. 결과 비교

| 지표 | 개선 전 | 개선 후 | 변화 |
|---|---:|---:|---:|
| 전체 승률 | 63.3% | 75.3% | +11.9%p |
| 추천 추종 승률 | 75.8% | 100.0% | +24.2%p |
| 숙련 난이도 승률 | 27.5% | 59.2% | +31.7%p |
| 엔진 무효 행동 | 308회 | 0회 | -100% |
| 숨은 표적 오조작 | 308회 | 50회 | -83.8% |
| 안내 없는 턴 종료 막힘 | 1,844회 | 0회 | -100% |
| 조장 전투불능 | 600명 | 403명 | -32.8% |
| 평균 라운드 | 4.98 | 4.71 | -0.27 |

개선 후 남은 숨은 표적 오조작 50회는 엔진에 전달되지 않는다. UI가 자동 개시하거나 즉시 안내해 모두 안전하게 차단한다.

## 6. 플레이 성향별 최종 결과

| 성향 | 전투 | 승률 | 엔진 무효 행동 | 평균 라운드 |
|---|---:|---:|---:|---:|
| 추천 추종 | 480 | 100.0% | 0 | 4.07 |
| 공격 우선 | 480 | 78.3% | 0 | 3.77 |
| 방어 우선 | 480 | 51.2% | 0 | 6.28 |
| 초심자 무작위 | 480 | 71.5% | 0 | 4.74 |

방어 우선 플레이는 고의로 공격 기회를 자주 포기하기 때문에 가장 낮은 승률을 유지한다. 추천 추종이 모든 임무에서 승리하므로, 전투 규칙을 아직 이해하지 못한 사용자도 `추천 즉시 실행`으로 진행할 수 있다.

## 8. 브라우저 확인

로컬 전체판 `http://127.0.0.1:4173`에서 다음을 확인했다.

- 타이틀 화면 정상 렌더링
- 라온 시점 문구와 세 개의 저장 슬롯 노출
- 시작, 진실 기록, 인물 도감 진입 버튼 노출
- 빈 화면 및 Vite 오류 오버레이 없음
- 브라우저 페이지 오류 없음

헤드리스 브라우저의 Canvas 세션은 마을 Phaser 장면에서 응답 제한에 걸렸다. 이는 일반 브라우저에서 재현된 애플리케이션 오류가 아니라 자동화 환경의 그래픽 세션 제약이며, 마을 상태·이동·랜드마크·NPC 기억은 별도 엔진 테스트에서 통과했다. 타이틀 검증 화면은 `artifacts/browser/01-title.png`에 보존했다.

전투 방식의 불명확성, 숨은 표적 오조작, 추천 행동의 이중 입력, 조용한 턴 종료 차단, 모바일 직접 조작 부재와 숙련 난이도의 과도한 압박을 수정했다.
