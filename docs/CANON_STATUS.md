# 정사 판정과 원전 보존

## 원전 계층

1. `docs/source/world-bible-v3.1.docx` — 제공된 편집본의 보존 사본
2. `docs/source/world-bible-v3.1.md` — 전체 텍스트·표를 추출한 검색용 사본
3. `public/content/world-bible-v3.1.json` — 868개 문단과 313개 표를 구조화한 런타임용 사본
4. `src/data/lore.ts` — 현재 프로토타입이 사용하는 선별 정사

원전의 세부 설정은 삭제하지 않는다. 게임에 아직 등장하지 않는 정보는 미구현일 뿐 폐기가 아니다.

## 네 가지 판정 상태

원전의 「문서 사용 안내」와 §196은 확정 정사와 설계안·미확정을 함께 보존한다고 명시한다. **원전에 등장한다는 사실과 사용자가 확정했다는 사실을 구분한다.** 아래 상태는 설정의 판정이며, 플레이어가 이미 알게 된 정보인지와는 별개다.

| 상태 | 데이터 값 | 적용 기준 | 제작·노출 기준 |
|---|---|---|---|
| 원전 근거 | `source-backed` | 원전의 해당 절에 직접 적혀 있으나 별도의 사용자 확정 기록까지 확인한 것은 아님 | 근거 절과 그 절의 설계·미정 여부를 함께 확인한다. 추론을 확정 설정에 덧붙이지 않는다. |
| 사용자 확정 | `user-confirmed` | 작가의 명시적 확정·정정이 확인되거나, 원전 §196이 작가 확정 사례로 직접 지목함 | 이후 명시적 정정 전까지 사건 인과의 기준으로 사용한다. |
| 각색 초안 | `adaptation-draft` | 원전의 방향을 게임의 장소·대사·전투·선택 장면으로 확장한 제안 | 제작 검토용이다. 구현·데이터 수량·플레이 여부가 정사 승격을 뜻하지 않는다. |
| 미정 | `undecided` | 원전이 질문이나 후보로 남겼거나, 채택 근거가 없음 | 한 갈래를 확정 결말처럼 쓰지 않는다. 미정인 사실과 관련된 각색 후보는 별도로 보존한다. |

## 대서사 충돌 판정과 출처

모든 원전 절 번호는 [보존한 v3.1 검색 사본](source/world-bible-v3.1.md)을 가리킨다. 원전 본문은 이번 교정에서 수정하지 않았다. `grandStory.ts`는 원전 자체가 아니라 제작자가 읽는 각색 데이터다.

| 검토 항목 | 현재 판정 | 근거 | 적용 결과 |
|---|---|---|---|
| 해찬이 모두를 구함 / 가람만 즉시 동조 / 모든 권능 소멸 | 사용자 확정 | §196이 작가 확정 사례로 직접 명시, §134의 5~10항 | 각색 장면에서도 이 인과를 바꾸지 않는다. |
| 아케로의 빛 이후 반대파의 붉은 머리·날개 상실·사능 상실 | 원전 근거 | §4 「체시의 정복과 내부 분열」, §15 「사능」 | 변화는 최초의 빛 이후에만 묘사한다. |
| 데닌이 반대파 자신인지 후손의 별도 명칭인지 | 미정 | §133의 첫 질문 | 반대파와 모든 후손이 동시에 데닌으로 변했다고 단정하지 않는다. |
| 카인의 조기교육·괴롭힘·패배·노력 부족 | 원전 근거 | §55 「카인」 | 기존 인물의 출발점으로 사용한다. 결말의 근거로 확대하지 않는다. |
| 카인의 생사·각성·몰락·속죄·장기적 책임 | 미정 | §55의 「최종 성장 또는 몰락의 방향은 미확정」, §133, §171.6.1의 결말 노선 제목 | `kain-final-choice`와 여섯 장면의 상태는 `undecided`. 생존과 긴 속죄를 필수 결말로 쓰지 않는다. |
| 카인의 병기열차·연결핀·오른손 감각 상실 | 각색 초안 | 기존 `grandStory.ts`의 장면 확장안. 위 원전 절에 채택 근거 없음 | 열차 장면은 후보로 남기고, 오른손 손상 확정 문장을 제거한다. 성공·생사·후유증은 미정으로 둔다. |
| 카인의 최종전 합류 | 미정 | 카인의 결말 미정에 종속됨 | `raon-style-final`의 고정 출연진·선택에서 카인 참여를 제거한다. 결말 확정 뒤 검토한다. |
| 라미의 구체 유년기·수용 구역·피난 공동체 배신 | 각색 초안 | §176은 상처·증오·기원을 설명할 방향만 제시함 | 기존 장면은 남기되 최초의 빛 이전 노동자·주민·난민을 데닌이나 데닌 선조로 확정하지 않는다. `denin-betrayal` ID는 저장·아트 참조 호환만을 위해 유지한다. |
| 라미 유년기 약 -120년 / 최초의 빛 약 -90년 | 미정 | §4·15·176에 이 수치와 라미의 정확한 연대 근거가 없음 | 두 숫자를 제거하고 사건 전후와 「연대 미정」으로 표시한다. 나머지 장면의 상대 간격·연도도 각색 초안이며 정사 연표가 아니다. |
| 라미의 출생 종족·저주받은 땅 기원·아케로의 빛 접근 방식 | 미정 | §133의 빛 접근 질문, §173·176의 향후 기원 공개 방향 | 출생 기록·실험 장치·설계 탈취는 제안이다. 최초의 빛 이전 「고대 빛 잔해」 서술과 설계 탈취 확정을 제거한다. |
| 라미의 권능 무효화 | 원전 근거 | §15. 이능은 §16의 별도 계통 | `nullification-awakens`가 이능까지 약화시킨다고 단정하지 않도록 교정한다. |
| 5부·86화·516장면의 세부 대서사 | 각색 초안 | §2·134·176의 공개 방향을 확장한 `GRAND_STORY_BLUEPRINT.md`와 `grandStory.ts` | 수량은 제작 계획 데이터의 개수다. 사가·에피소드·장면에 `canonStatus` / `canonNotice`를 제공하며, 장면이 에피소드의 판정을 상속한다. |

상태를 올릴 때는 해당 행에 사용자 확정 발언이나 원전의 명시적 확정 절을 추가하고, 관련 데이터와 회귀 테스트를 함께 갱신한다. 「계속 제작」 요청이나 초안의 기존 저장 사실만으로 미정 항목을 확정하지 않는다.

## 최종 정사로 우선 적용한 항목

- 제목은 《발할라》에서 《라온제나》로 변경되었다.
- 배경은 체시가 정복한 대체지구이며, 현재는 A.S. 84다.
- 대전쟁 말기 라미는 완전한 빛으로 체시·데닌·관련 혼혈의 소거를 시도했다.
- 라미에게 즉시 맞선 인물은 해찬과 가람뿐이다.
- 가람은 해찬의 길과 피난로를 만들었고, 완전한 빛의 핵심을 파괴한 사람은 해찬이다.
- 해찬은 라미의 권능 무효화 범위에서 시간 권능 없이 체능의 극의를 발현했다.
- 극의의 대가로 해찬의 다리와 기맥은 영구 손상되며 치유 이능으로 복구되지 않는다.
- 불완전해진 빛은 종족 대신 모든 권능의 근원을 태웠다. 현재편에서 권능은 사용할 수 없다.
- 다른 1세대는 주저하거나 일부가 라미 편에서 해찬을 막았다. 뒤늦은 구조 활동은 해찬의 구원을 분산하지 않는다.
- 진훤은 전후 안정을 위해 해찬과 반란군 분열의 역사를 삭제했다.
- 마루의 권능 ‘운’은 이미 소멸했다. 진훤과의 계약은 남은 체능·이능·능동 전투 행위를 봉인한다.
- 마루의 봉인은 키티가 즉각적인 죽음의 위험에 처할 때만 필요한 범위에서 해제된다.
- 진훤이 죽어도 계약은 자동 해제되지 않는다.
- 프시케 제5기는 크라우드·캄프타·아델린·브리짓·아벨과 조장 밖의 모이라로 구성한 ‘봉합의 세대’다.
- 아델린은 전 제3기 제2조장이며, 이능 `공명망`의 생존자다.

## 용어

| 용어 | 판정 |
|---|---|
| 극치 | 반복해서 사용할 수 있는 완성된 숙련의 경지 |
| 극의 | 미래의 가능성과 신체 기능을 현재로 당겨 쓰는 비가역 초월 |
| 권능 | 대가를 수반하는 신적 개념 조작. A.S. 0에 소멸 |
| 사능 | 체시의 종족 고유 능력. 직접 대가 없이 제약 안에서 사용 |
| 이능 | 신성 주입으로 만들어진 단일 기능형 인공 능력 |
| 체능 | 기를 신체·무기·감각에 순환시키는 계승 가능한 무예 |

## 충돌 처리 원칙

- 후속 대화에서 명시적으로 정정된 설정이 초기 설정보다 우선한다.
- 사용자 확정이 없는 보완은 `설계안`으로만 취급한다.
- 권능 소멸 이후 시간 권능으로 해찬의 보폭을 보완하는 초기안은 폐기한다.
- 모두의 협력으로 멸종을 막았다는 초기 해석은 폐기한다. 최종 인과는 “해찬이 모두를 구했고 가람만 처음부터 함께했다”이다.
- 마루의 계약이 운의 권능을 봉인한다는 표현은 폐기한다. 운은 계약 전에 소멸했다.
- 반데닌의 정확한 정의, 가람의 혈통 비율, 라미파 최종 명단, 니아의 이능, 천공의 검, 카인의 결말은 확정 전까지 미정으로 유지한다.

## 독자 유도 원칙

- 현재에서 영웅을 믿게 한다.
- 과거에서 영웅들을 사랑하게 한다.
- 진실로 그 사랑을 배신한다.
- 다시 현재에서 선대를 이해하되 넘어선다.
- 라미편에서 최초의 상처를 이해시키지만 면죄하지 않는다.

캐릭터를 전부 좋아하게 만드는 것이 목적이 아니다. 각 선택의 뿌리를 이해시킨 뒤, 독자가 지지와 선 긋기를 스스로 결정하게 만든다.
