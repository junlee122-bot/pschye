# 정사 판정과 원전 보존

## 원전 계층

1. `docs/source/world-bible-v3.1.docx` — 제공된 편집본의 보존 사본
2. `docs/source/world-bible-v3.1.md` — 전체 텍스트·표를 추출한 검색용 사본
3. `public/content/world-bible-v3.1.json` — 868개 문단과 313개 표를 구조화한 런타임용 사본
4. `src/data/lore.ts` — 현재 프로토타입이 사용하는 선별 정사

원전의 세부 설정은 삭제하지 않는다. 게임에 아직 등장하지 않는 정보는 미구현일 뿐 폐기가 아니다.

## 최종 정사로 우선 적용한 항목

- 제목은 《발할라》에서 《라온제나》로 변경되었다.
- 배경은 체시가 정복한 대체지구이며, 현재는 A.S. 84다.
- 대전쟁 말기 라미는 완전한 빛으로 체시·데닌·관련 혼혈의 소거를 시도했다.
- 라미에게 즉시 맞선 인물은 해찬과 가람뿐이다.
- 가람은 해찬의 길과 피난로를 만들었고, 완전한 빛의 핵심을 파괴한 사람은 해찬이다.
- 해찬은 라미의 권능 무효화 범위에서 시간 권능 없이 체능의 극의를 발현했다.
- 극의의 대가로 해찬의 다리와 기맥은 영구 손상되며 치유 이능으로 복구되지 않는다.
- 불완전해진 빛은 종족 대신 모든 권능의 근원을 태웠다. 현재편에서 권능은 사용할 수 없다.
- 다른 1세대는 주저하거나 일부가 라미 편에서 해찬을 막았다. 뒤늦은 구조 활동은 해찬의 구원을 분산하지 않는다.
- 진훤은 전후 안정을 위해 해찬과 반란군 분열의 역사를 삭제했다.
- 마루의 권능 ‘운’은 이미 소멸했다. 진훤과의 계약은 남은 체능·이능·능동 전투 행위를 봉인한다.
- 마루의 봉인은 키티가 즉각적인 죽음의 위험에 처할 때만 필요한 범위에서 해제된다.
- 진훤이 죽어도 계약은 자동 해제되지 않는다.
- 프시케 제5기는 크라우드·캄프타·아델린·브리짓·아벨과 조장 밖의 모이라로 구성한 ‘봉합의 세대’다.
- 아델린은 전 제3기 제2조장이며, 이능 `공명망`의 생존자다.

## 용어

| 용어 | 판정 |
|---|---|
| 극치 | 반복해서 사용할 수 있는 완성된 숙련의 경지 |
| 극의 | 미래의 가능성과 신체 기능을 현재로 당겨 쓰는 비가역 초월 |
| 권능 | 대가를 수반하는 신적 개념 조작. A.S. 0에 소멸 |
| 사능 | 체시의 종족 고유 능력. 직접 대가 없이 제약 안에서 사용 |
| 이능 | 신성 주입으로 만들어진 단일 기능형 인공 능력 |
| 체능 | 기를 신체·무기·감각에 순환시키는 계승 가능한 무예 |

## 충돌 처리 원칙

- 후속 대화에서 명시적으로 정정된 설정이 초기 설정보다 우선한다.
- 사용자 확정이 없는 보완은 `설계안`으로만 취급한다.
- 권능 소멸 이후 시간 권능으로 해찬의 보폭을 보완하는 초기안은 폐기한다.
- 모두의 협력으로 멸종을 막았다는 초기 해석은 폐기한다. 최종 인과는 “해찬이 모두를 구했고 가람만 처음부터 함께했다”이다.
- 마루의 계약이 운의 권능을 봉인한다는 표현은 폐기한다. 운은 계약 전에 소멸했다.
- 반데닌의 정확한 정의, 가람의 혈통 비율, 라미파 최종 명단, 니아의 이능, 천공의 검, 카인의 결말은 확정 전까지 미정으로 유지한다.

## 독자 유도 원칙

- 현재에서 영웅을 믿게 한다.
- 과거에서 영웅들을 사랑하게 한다.
- 진실로 그 사랑을 배신한다.
- 다시 현재에서 선대를 이해하되 넘어선다.
- 라미편에서 최초의 상처를 이해시키지만 면죄하지 않는다.

캐릭터를 전부 좋아하게 만드는 것이 목적이 아니다. 각 선택의 뿌리를 이해시킨 뒤, 독자가 지지와 선 긋기를 스스로 결정하게 만든다.
