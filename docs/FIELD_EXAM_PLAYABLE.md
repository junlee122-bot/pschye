# 폐광 현장시험 플레이 구간

작성 기준: 2026-09-15. 체크 항목은 자동 검증과 실제 화면 확인을 구분한다.

## 각색 범위

[원전 v3.1](source/world-bible-v3.1.md) §74는 목표·명령·사람 중 무엇을 우선하는지 관찰하는 입단 예비과정을 제시한다. §75의 현장시험 「폐쇄구역 13호」는 미르의 감독 아래 살아 있는 실험체를 비살상으로 보호하는 개발안이다. **현재 `originStory.ts`의 선발 11일차 폐광·깃발·고립 지원자 두 명은 기존 게임 각색이며, 13호 사건과 동일한 정사 사건으로 확정하지 않는다.**

이번에는 기존 `field-exam`의 선택 ID·대사·후속 흐름을 유지하고 구조 행동을 확장한다. 13호의 실험체·미르 감독·제6기 방해, 제작자용 `grandStory.ts`의 독·침투·폐허 도시를 합치지 않는다. 낡은 지지대의 붕괴를 누군가의 고의 범행으로 확정하지 않으며, 지원자들의 이름·출신·영구 후유증도 추가하지 않는다. 카인이 확보한 깃발의 소유·개수가 불명확하므로 새 깃발이나 탈환 임무를 만들지 않고 카즈린의 역할은 ‘시험 목표 유지’로 표시한다.

원전 §53·76·77에 따라 초기 라온은 체능 기본기와 지구력이 부족하다. 짧게 통로를 받치고 동료에게 도움을 요청할 수 있지만, 16꽃잎·해찬류·완성된 방벽·미래 예지·괴력을 주지 않는다. 결의 경로에서는 **라온이 잠깐 버틴 뒤 하도리가 하중을 인계**한다. 하도리가 이미 체능을 완성했거나 라온이 장시간 갱도를 떠받쳤다는 뜻이 아니다.

## 조작과 세 선택

공통 목표는 두 통로에 고립된 지원자 각 한 명을 구조하고 **모두와 함께 철수**하는 것이다. 각 통로의 진행도는 `0~3`이며, 순서대로 접근 → 구조 보조 → 출구 인도를 나타낸다. 매 턴 라온·레오에게 각각 왼쪽 통로(`left`), 오른쪽 통로(`right`), 통로 받치기(`brace`)를 정한 뒤 함께 실행한다.

| 선택 | 역할과 규칙 차이 | 완료 뒤 보여 줄 사실 |
|---|---|---|
| `rescue-team` · 연민 | 전원이 구조에 집중한다. 카즈린의 지원으로 받치기 한 명령당 버팀 `+3`. | 두 지원자와 함께 돌아온다. 낮아진 시험 점수와 구조에 함께한 사람들을 기억한다. |
| `split-route` · 통찰 | 라온·레오가 서로 다른 미완료 통로를 구조하면 그 턴 하중 `-1`(최소 1). 카즈린은 화면 밖에서 시험 목표를 유지한다. | 두 지원자가 돌아오고 역할 분담이 하나의 명령으로 이어진다. |
| `defy-order` · 결의 | 첫 턴 라온의 받치기가 필수다. 하도리의 하중 인계 뒤에는 라온도 자유롭게 명령을 고른다. | 하도리에게 하중을 맡긴 뒤 두 지원자와 라온이 돌아온다. |

선택별 안내는 `src/data/fieldExam.ts`의 `fieldExamApproaches`를 사용한다. `pending`은 방침만 말하며 구조 완료를 주장하지 않는다. `completion`은 실제 철수 확인 뒤에만 표시한다.

## 판정과 저장

- 통로 버팀은 6으로 시작하며 최대 8이다. 기본 받치기는 한 명령당 `+2`이고, 받치기를 먼저 반영한 뒤 행동 후 하중을 소모한다. 하중은 매 3번째 턴에 3, 나머지 턴에는 2다.
- 8턴 안에 두 통로의 구조가 모두 끝나고 버팀이 남으면 `return`이다. 8번째 턴의 구조 완료도 허용한다. **버팀 0은 구조 완료보다 먼저 실패로 판정**한다.
- `return`에서 명시적으로 ‘모두와 함께 철수’를 누르면 `complete`가 된다. 그때 기존 결과 플래그와 NPC의 완료 기억을 한 번 기록한다. 구조 중단·재도전은 조작 시도의 실패이며, 사망·퇴학을 정사로 기록하지 않는다.
- 상태는 `ready → active → return → complete`, 실패 시 `active → failed → active`다. 시간 제한·통로 붕괴 뒤에는 명시적으로 재도전한다. 턴·버팀·낙석 수치는 게임 규칙이며 세계관의 물리 법칙이 아니다.
- 선택 성향, 기존 평가 점수 `5 / 6 / 5`, 레오 관계는 선택 의도로 한 번 유지한다. 구조 실행·재도전·철수에서 추가 경험치나 선택 보상을 주지 않는다. ‘시험 점수가 낮아졌다’는 기존 서술을 이유로 별도 점수 차감을 추가하지 않는다.
- 저장 형식은 v10의 선택 필드 `originStory.fieldExam`이다. 선택만 한 구버전 저장은 기존 선택·수치 보상을 유지한 `ready`로 이어가고, 선지급된 결과 플래그·완료 기억은 실제 철수까지 보류한다. 이미 장면 완료·후속 장면·서장 완료에 도달한 저장은 재시험을 강요하지 않는다.

완료 후 기존 선발 12일차 `suspended-candidate`로 합류한다. 원전 §76~78의 활동 보류 → 마루 수련 → 16꽃잎 → 조장 선발 인과를 바꾸지 않는다. 하도리 1·라온 2·카즈린 3·카인 4·레오 5·크리스 6의 순위와 입단은 선택·턴 수·재시도로 달라지지 않는다.
