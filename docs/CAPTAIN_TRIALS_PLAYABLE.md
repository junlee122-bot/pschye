# 조장 선발전·입단 플레이 구간

작성 기준: 2026-09-15. 원전과 기존 `originStory.ts`는 변경하지 않는다. 자동검사와 실제 화면 검증은 따로 기록한다.

## 원전과 각색 경계

[원전 v3.1](source/world-bible-v3.1.md) §53·78에 따라 카인전은 습관을 읽는 판단과 마루계 해찬류 16꽃잎의 결합, 카즈린전은 오래 지켜본 흐름을 읽은 **근소한 승리**, 하도리전은 **한 방에 기절하는 패배**로 끝난다. 최종 순위는 하도리 1, 라온 2, 카즈린 3, 카인 4, 레오 5, 크리스 6이다. 선택과 재시도로 승자·입단 여부·순위를 바꾸지 않는다.

라온의 기본기·지구력·검술 지속성 부족은 남는다(§53). 이번 입력은 완성된 라온류·극의·권능이나 영구 능력치의 획득이 아니다. 하도리는 아직 체계적인 기술이 없는 괴력의 후보(§52)이므로 새로운 필살기를 부여하지 않는다. 카즈린이 일부러 봐주거나 보호 본능 때문에 멈춰서 졌다고 설명하지 않는다. 승부는 비살상으로 마무리하며 사망·절단·영구 장애와 카인의 장기 결말을 추가하지 않는다.

기존 `hadori-wall`은 이미 패배 후 의무동에서 대화하는 장면이다. 따라서 **새 하도리 도전 → 한 방 패배 → 의무동 이동 확인 → 기존 후일담 세 선택** 순서를 지킨다. 준비 화면에서 패배 후 대사·후일담 선택을 먼저 보여 주지 않는다. 기존 서술의 ‘첫 꽃잎이 피기도 전에’와 통찰 결과의 ‘열두 번째 꽃잎부터 다리가 무너졌다’는 서로 맞지 않는다. 원전은 순번을 확정하지 않으므로 새 로그·안내에는 ‘하도리의 한 방으로 도전전은 끝났다’처럼 순번 없는 표현만 쓴다. 기존 문구는 보존하며, 이 문서는 해당 불일치를 해결된 정사로 간주하지 않는다.

## 선택과 공방

카인·카즈린의 기존 여섯 선택은 첫 공방의 의도다. `captainTrialApproaches.pending`은 방침만, `completion`은 승부 확인 뒤의 결과만 표현한다. 카인전의 상대를 다치게 하지 않기·습관에서 틈 찾기·자기 이름으로 나아가기, 카즈린전의 대등하게 믿기·익숙한 박자 바꾸기·나란히 서기를 유지한다. 하도리 도전에는 미리 고르는 성향 선택이 없다.

| 규칙 | 이번 플레이 각색 |
|---|---|
| 공통 자원 | 균형 최대 6, 호흡 최대 4, 승부 진행 목표 3, 최대 18행동. 대기 시간은 흐르지 않는다. |
| 카인의 공방 | 찌르기 → 회수 → 횡공격 → 회수 순서를 반복한다. |
| 카즈린의 공방 | 횡공격 → 찌르기 → 회수 순서를 반복한다. 두 방어를 모두 맞춰야 반격할 틈이 열린다. |
| 방어와 반격 | 찌르기는 `parry`(창 흘리기), 횡공격은 `sidestep`(비켜딛기). 상대 회수 때 열린 틈에서 `counter`(검로 잇기) 성공 시 진행 +1. 방어·반격은 각각 호흡 1을 쓴다. |
| 호흡 회복 | `recover`(거리 두고 호흡)는 호흡 +2. 상대 회수 중이면 균형도 +1. |
| 연민 | 호흡 회복 +3, 상대 회수 중 균형 회복 +2. |
| 통찰 | 방어 호흡 소모 0. 반격은 호흡 1을 쓴다. |
| 결의 | 성공한 반격의 진행 +2. 잘못 대응한 균형 손실은 3으로 커진다. |
| 중단 | 잘못된 방어나 공격 중 회복은 균형 -2(결의 -3). 균형이 0이면 성공 조건보다 먼저 중단한다. 호흡이 부족한 행동은 실행할 수 없다. 시간 초과·중단은 시도 상태이며 정사상 탈락이나 부상이 아니다. |

수치·공격 반복·버튼은 읽기와 대응을 표현하는 게임 규칙이다. 원전 기술의 정확한 동작 수·위력·승부 시간으로 환산하지 않는다. 하도리전은 준비 후 `challenge`(첫발 내딛기) 한 번으로 한 방 패배에 도달한다. 이는 `failed`가 아닌 정상적인 `resolved` 단계이며 승리할 때까지 재도전하게 만들지 않는다.

## 진행·저장·후속 장면

상태는 `ready → active → resolved → complete`, 카인·카즈린 시도 중단은 `active → failed → active`다. 선택 필드 `originStory.captainTrials`에 장면별로 장면 ID, 선택 ID(하도리는 없음), 단계, 시도·행동 수, 균형·호흡·진행·방어 연결과 현장 기록을 보존한다. 카즈린의 첫 방어 뒤 `opening`은 다음 방어와 이어 갈 기억이며, 상대가 회수 중이고 `opening`이 참일 때만 실제 반격할 틈으로 안내한다. 화면을 읽거나 저장을 닫아 둔 시간은 공방을 진행시키지 않는다. `resolved`에서 명시적으로 승부를 확인해야 `complete`가 되고 다음 대결로 넘어간다. 하도리는 의무동으로 이동을 확인한 뒤 기존 후일담으로 넘어간다.

선택할 때 기존 성향·평가 점수·관계·유대 수치를 한 번만 유지한다. 카인·카즈린의 결과 플래그와 완료 NPC 사실은 승부 확인까지 지연한다. 재시도·확인 반복·이전 시도의 늦은 입력으로 중복 보상을 주지 않는다. 새 XP·스킬 포인트·정식 작전 보상은 없다. 기존 선택만 남은 저장은 선택과 지급된 수치를 존중하며 미완 대결을 이어 간다. 이미 후속 장면이나 서장 완료에 도달한 저장에 재대결을 강요하지 않는다. 선택 필드 추가는 기존 저장과 호환되게 처리한다.

`seventh-oath`는 세 대결과 하도리 후일담 뒤 기존 순서대로 진행한다. 입단 선택은 조장으로서의 태도다. 여섯 사람이 처음부터 완성된 팀이 되었다거나 첫 공식 작전을 이미 성공했다고 확정하지 않는다. 기존 서장 완료·첫 작전 진입 경로를 유지하며 정식 전투의 체크포인트·정산을 이 대결에 섞지 않는다.

## 이번 실제 화면 확인 범위

2026-09-15, 프로덕션 설정으로 빌드한 별도 검증 화면에서 카인 통찰 선택·대결 시작·키보드 첫 방어를 확인했다. 실행 뒤 동작 1, 균형 6, 호흡 4, 승부 진행 0이며 반격할 틈이 열렸다. 390px 화면의 동작 선택·예고·실행 폼을 촬영했고 가로 넘침은 없었다. 시작점은 앞선 장면을 준비한 시드에서 수련 API를 완료한 상태이므로 새 게임부터의 직접 완주로 세지 않는다.

브라우저 조작 도구의 마우스 입력 시간 초과가 연결 복구 뒤 재발했고, 기존 연결에서 키보드만 사용하는 대안도 입력 시간 초과로 중단됐다. 타이틀 이동 완료·새로고침 후 이어하기·카인전 완료 이후 세 대결 연결·입단·첫 작전 준비는 이번 실제 조작으로 확인하지 못했다. 위 수동 계획의 전체 항목을 통과로 표시하지 않으며, 자동 검사에서 확인한 진행·저장 결과와 구분한다.
