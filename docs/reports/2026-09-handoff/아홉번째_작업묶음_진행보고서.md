2026-09-15

**Unity 프로젝트의 소스·연습 장면·라온 모델을 준비했습니다. 실제 Unity 컴파일과 플레이 검증은 대기 중입니다.** 현재 PC의 기본 설치 경로와 설치 기록에서 Unity Editor를 찾지 못했으므로 이번 묶음을 실행 검증까지 완료했다고 판정하지 않습니다.

- 라온의 카메라 기준 걷기·달리기·회전·점프·중력·벽/턱/경사 충돌·낙하 후 복귀.
- 3인칭 카메라 회전·줌·벽/모서리 충돌·거리 복귀.
- 평지·계단·벽·경사·급경사·점프 발판이 있는 연습장과 조작 안내·일시정지·진단 표시.
- 라온 비동기 모델 로드, 실패·재시도·취소·파괴 처리, idle/walk/run/jump 연결.
- Editor 준비 메뉴와 설치 탐지·검증·테스트·Windows 빌드용 PowerShell 실행 스크립트.

기존 웹 소스 117개, 공개 자산 2,181개, 기존 Unity 캐릭터 검수 프로젝트 9개 파일은 Git 기준 변경하지 않았습니다. 웹과 Unity의 역할은 README와 엔진 문서에 정리했습니다.

## 모델에서 해결한 문제

라온 원본 v2는 내장 WebP 텍스처를 필수로 요구했습니다. 선택한 Unity 로더용 파생 GLB를 만들면서 텍스처 22개를 PNG로 변환했습니다. **모든 이미지의 디코딩된 RGBA 픽셀과 비이미지 bufferView가 보존됐습니다.**

| 항목 | 결과 |
|---|---|
| 원본 파일 크기 | 5,427,548바이트 |
| Unity 파생본 크기 | 20,174,828바이트 |
| 삼각형 / 관절 | 42,592 / 33 |
| 표정 모프 / 동작 클립 | 20 / 16 |
| 재질 / 텍스처 | 8 / 22 |
| 머리카락 | 양면 BLEND 재질 보존 |

모델은 기존 자동 리토폴로지 후보입니다. 이번 변환으로 최종 스키닝·표정·머리카락 품질이 완성된 것은 아닙니다. 별도 낙하 클립과 발 IK도 아직 없습니다.

## 이어서 할 순서

1. Unity Editor **6000.0.75f1** 설치 또는 기존 `Unity.exe` 경로 확인.
2. `Verify`로 실제 패키지 해결·컴파일·장면 준비 확인.
3. `EditMode`·`PlayMode` 실행, 실패 원인을 수정하고 결과 XML 확보.
4. 연습장에서 이동·충돌·카메라·모델·일시정지·로드 재시도를 실기 검수.
5. Windows 빌드에서 모델·재질·입력을 확인한 뒤 9묶음 완료 판정.
6. 다음 묶음의 첫 3D 여정: 마을·연결 길·폐허·귀환, 상호작용·검술·월드 상태·체크포인트 연결.

현재 프로젝트는 키보드·마우스 연습장 범위입니다. 캠페인·전투·웹 세이브 이전은 구현하지 않았습니다. 입력·시각 검증을 통과한 기반 위에서 다음 콘텐츠를 붙입니다.
