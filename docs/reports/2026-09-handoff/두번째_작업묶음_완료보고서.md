## 기존 저장과 공개 순서

기존 클리어·등급·보상과 truth 토큰은 유지한다. 다만 이전 버전은 임무만 깨도 truth 토큰을 지급했으므로 실제 증언 획득의 증거로 사용하지 않는다. 완료한 작전을 재도전해 해당 기술로 증언을 이끌어 내고 승리하면 새 기록이 열린다. 저장 버전은 v10을 유지한다.

현재 미구현 후반 서사와 인물의 최종 진실은 일반 게임에서 공개하지 않는다. 새 플레이 장면을 연결할 때 공개 근거를 함께 추가해야 한다. 이 작업은 화면의 스포일러 공개 순서를 다루며 모든 정적 원본 파일을 비밀로 만드는 보안 장치는 아니다.
