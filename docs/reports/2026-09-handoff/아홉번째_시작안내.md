# 라온 Unity 기반 시작 안내

현재 소스는 준비됐지만 Unity Editor가 확인되지 않아 컴파일·플레이 검증은 아직 진행하지 못했습니다.

## 프로젝트 열기

Unity Hub의 프로젝트 열기에서 다음 폴더를 선택합니다. 기준 Editor는 **6000.0.75f1**입니다.

```text
<LOCAL_REPOSITORY>\unity\PsycheAdventure
```

패키지 가져오기가 끝나면 **Raonjena → Adventure → Prepare Project**, 이어서 **Open Foundation Scene**을 실행하고 Play를 누릅니다. 모델 로드 실패 시 화면에 이유와 재시도 버튼이 표시됩니다.

## 조작

| 키 | 기능 |
|---|---|
| WASD·방향키 | 이동 |
| Shift | 달리기 |
| Space | 점프 |
| 오른쪽 마우스 드래그·휠 | 카메라 회전·줌 |
| C / R | 카메라 초기화 / 시작 위치 복귀 |
| Esc / F3 | 일시정지 / 진단 표시 |

## 검증 명령

저장소 폴더에서 PowerShell을 엽니다.

```powershell
.\tools\unity\Invoke-Adventure.ps1 -Action Probe
.\tools\unity\Invoke-Adventure.ps1 -Action Verify
.\tools\unity\Invoke-Adventure.ps1 -Action EditMode
.\tools\unity\Invoke-Adventure.ps1 -Action PlayMode
.\tools\unity\Invoke-Adventure.ps1 -Action Build
```

다른 위치에 설치한 경우 각 명령에 `-UnityEditorPath '실제 Unity.exe 전체 경로'`를 붙입니다. 탐지는 소프트웨어를 설치하거나 로그인하지 않습니다. 로그·테스트 XML은 프로젝트의 `TestResults`에 남습니다. Build 성공 시 `Builds/RaonFoundation/RaonFoundation.exe`가 생성됩니다. 아직 생성된 플레이어 빌드는 없습니다.

연습장에서 벽·계단·경사·천장·점프·낙하·카메라를 확인하고, 라온의 발·관절·피부·머리카락이 정상인지 확인합니다. Unity 테스트 34개는 작성 상태이며, 실제 통과 여부는 위 명령 실행 뒤 판정합니다.
