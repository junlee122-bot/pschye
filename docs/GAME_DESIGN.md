# 게임 설계서

## 1. 제품 정의

《라온제나》는 캐릭터 수집형 도감이 아니라 **공식 역사와 실제 역사의 간극을 플레이로 해석하는 내러티브 전술 RPG**다. 플레이어는 프시케 제7기의 조장들을 지휘하고, 임무에서 발견한 기록으로 영웅에 대한 기존 인식을 뒤집는다.

핵심 판타지는 세 문장으로 정의한다.

1. 선대의 체능을 전술 조합으로 계승한다.
2. 같은 사건을 공식 기록과 생존자의 기억으로 다시 읽는다.
3. 선대보다 강해지는 대신, 선대가 선택하지 못한 답을 만든다.

### 고정 주인공 원칙

- 플레이어 아바타는 라온으로 고정한다.
- 라온은 모든 주요 작전에 출전하며, 파티 편성에서 제외할 수 없다.
- 메타 시스템도 제국 지휘관의 관리가 아니라 라온의 훈련, 동료와의 약속, 기록 해독으로 표현한다.
- 정보는 라온이 알게 된 순서로 공개하며, 라온이 모르는 진실은 UI가 먼저 단정하지 않는다.

### 핵심 서사 루프

| 단계 | 플레이어 경험 | 게임 효과 |
|---|---|---|
| 장면 | 라온의 시야와 오감으로 현장을 받아든인다. | 임무 규칙과 위험을 자연스럽게 학습한다. |
| 내면 | 라온이 무엇을 두려워하고 의심하는지 듣는다. | 다음 선택의 감정적 비용을 알려준다. |
| 대화 | 동료가 서로 다른 해답을 제안한다. | 전술·관계·성격을 동시에 노출한다. |
| 선택 | 연민·통찰·결의 중 현재의 라온다운 답을 고른다. | 영구 경향치와 즉시 전투 보너스를 변경한다. |
| 전투 | 적의 의도를 읽고 3회의 명령을 조합한다. | 집중 연계, `BREAK`, 방벽, 사기 운용으로 선택을 행동으로 바꾼다. |
| 회고 | 결과를 라온의 독백으로 다시 읽는다. | 다음 장면의 관계, 진실, 선택 압력으로 되돌린다. |

### 선택의 전투 번역

- **연민:** 호송·민간인·구조 목표에 시작 방벽 `+24`.
- **통찰:** 확인된 적 전원에게 노출 `+1`.
- **결의:** 전투 시작 사기 `+20`.
- 같은 작전의 선택을 바꾸면 경향치도 이전 선택을 취소하고 재계산한다.
- 승리와 패배 모두 라온의 전용 회고를 남겨, 전투를 서사와 분리된 미니게임으로 끝내지 않는다.

## 2. 공개 순서

게임의 캠페인은 연대순이 아니라 진실 공개 순서를 따른다.

1. **프시케 제7기 전반** — 제국의 공식 역사를 믿게 한다.
2. **해찬편** — 대전쟁 세대를 사랑하게 한 뒤 그들의 분열을 보여준다.
3. **프시케 제7기 후반** — 선대의 기술을 계승하되 결론은 거부한다.
4. **라미편** — 최초의 피해를 이해시키지만 멸종 계획을 면죄하지 않는다.

현재 프로토타입은 첫 단계의 8개 작전선을 모두 완전한 전투로 구현한다. 각 작전은 적 구성만 바꾸지 않고 고유 전장 규칙, 장비 보상, 세력 변화를 가진다.

## 3. 플레이 루프

```text
전선 지도에서 작전 선택
→ 4~6인 출격조·장비·본부 시설 정비
→ 지휘 덱에서 자원·행동력·다음 목표 확인
→ 하루 3회의 지휘 행동으로 훈련·유대·현장 활동·제작
→ 세 분야를 고르게 수행해 균형 지휘 보상 확보
→ 파견 작전과 세력 평판 관리
→ 작전실 브리핑과 교리 선택
→ 6인 전술 전투
→ 생환·보호 목표·등급 정산
→ 경험치·보급·정보·유물 획득
→ 공식 기록과 비공식 기록 해금
→ 다음 작전·시설·인물 해금
```

전투의 승리는 적 전멸만으로 계산하지 않는다. 호송 대상, 민간인, 퇴로, 아군 생환이 임무 등급의 중심이다. 이는 제3기 참사를 거친 프시케의 역사와 제5기 ‘봉합의 세대’의 교리를 게임 규칙으로 옮긴 것이다.

## 4. 구현된 제7기 전반 작전선

| 작전 | 유형 | 핵심 질문 | 상태 |
|---|---|---|---|
| 회색 교각 호송 | 호송 | 적을 잡는 것과 사람을 지키는 것 중 무엇이 먼저인가 | 플레이 가능 |
| 시티즌의 탄피 | 조사 | 제국의 부와 총성은 어디에서 연결되는가 | 플레이 가능 |
| 비어 있는 기수의 마을 | 방어 | 살아남은 사람의 기억이 공식 기록을 이길 수 있는가 | 플레이 가능 |
| 날개 없는 호송 | 구조 | 보호받을 가치의 기준을 누가 정하는가 | 플레이 가능 |

## 5. 첫 전투: 회색 교각 호송

### 임무 목표

- 주 목표: 마차를 6라운드 동안 지킨다.
- 보조 목표: 하늘의 저격수를 찾아 무력화한다.
- 서사 목표: 라온의 16꽃잎을 알아보는 적의 증언을 확보한다.

### 핵심 자원

- **지휘점:** 라운드마다 3점. 어느 조장을 먼저 움직일지 결정한다.
- **사기:** 기술과 보호 행동으로 축적한다. 100에서 합동기 사용이 가능하다.
- **마차 방벽:** 하도리·카즈린·레오가 회복할 수 있는 별도 보호 자원이다.
- **노출:** 은폐와 방어를 무너뜨리는 상태. 크리스와 카인이 주로 부여한다.

### 조장별 역할

| 인물 | 전술 역할 | 첫 장의 서사 기능 |
|---|---|---|
| 하도리 | 방벽, 기절, 전선 고정 | 힘을 쓰는 것보다 감당하는 법을 배운다. |
| 라온 | 단일·광역 검격 | 금지된 검의 첫 흔적을 드러낸다. |
| 카즈린 | 정밀 공격, 보호 전환 | 승리보다 보호 목표를 먼저 고른다. |
| 카인 | 노출, 고위험 일격 | 실제 실력과 오만을 동시에 보여준다. |
| 레오 | 회복, 피해 완화 | 명령이 끊겼을 때 조용히 중심이 된다. |
| 크리스 | 은폐 해제, 전장 읽기 | 가벼운 태도 아래의 관찰력과 책임을 드러낸다. |

## 6. RPG 메타 시스템

### 캠페인 저장

- 완료 임무, 최고 등급, 날짜, 지휘 레벨을 하나의 프로필에 저장한다.
- 첫 클리어만 자원과 경험치를 지급하고 재도전은 등급 개선에 사용한다.
- 선행 임무와 실제 전투 데이터 유무를 분리해 `잠김`, `출격 가능`, `개발 프리뷰`, `완료` 상태를 제공한다.

### 프시케 본부

- **진훤의 훈련장:** 기본 체력·방어와 기술점 성장.
- **삭제 기록 보관소:** 숨은 기록과 추가 임무 정보.
- **미르의 회복동:** 종족별 회복과 출전 안정성.
- **구세계 공방:** 체능 무구와 화기 대응 장비.
- **바이올렛 작전실:** 잠입·함정·비공식 임무선.

### 조장단 성장

- 레벨과 경험치, 유대, 장비 두 슬롯, 순차 기술 노드를 사용한다.
- 마지막 노드는 단순 수치 상승이 아니라 각 인물이 선대의 체능에서 개인류를 분리하는 서사적 관문이다.
- 본부 시설 레벨은 실제 전투의 체력·방어·기술 위력에 반영된다.
- 작전 전 4~6명을 편성하며, 실제 출격한 조장만 첫 클리어 경험치를 얻는다.
- 14종 장비는 주 무구와 보조 장비 슬롯에 장착되며 생명·방어·기술 위력을 직접 바꾼다.

### 세력과 파견

- 제국·민간 공동체·저주받은 땅·체시 생존권의 평판을 `적대–경계–중립–신뢰–맹약`으로 추적한다.
- 6개 파견은 전투 사이의 구조·조사·중재를 표현하며, 선행 작전과 보급 비용을 요구한다.
- 파견은 날짜를 진행시키고 자원·장비·평판을 바꾸지만 중복 보상을 허용하지 않는다.

### 일일 지휘

- 하루에 세 번 행동하며, 행동하지 않은 채 날짜만 넘겨 수입을 반복 획득할 수 없다.
- 다음 날로 넘어가면 사용한 행동 수에 비례해 소량의 보급·정보가 들어오고 행동이 회복된다.
- **개인 훈련:** 기본기·생환·지휘 중 하나를 골라 경험치와 기술점 또는 유대를 성장시킨다.
- **유대 훈련:** 두 조장의 관계를 누적해 30·60 지점에서 관계 기록을 해금한다.
- **현장 활동:** 도시 순찰, 철도 회수, 기록 해독, 국경 중재, 야전 치료, 체시 신호 추적을 반복 수행한다.
- **공방 제작:** 시설 레벨과 보급·정보·유물을 소모해 선대의 흔적이 남은 장비를 만든다.
- **균형 지휘 목표:** 개인 훈련·유대 훈련·현장 활동을 하루에 한 번씩 수행하면 보급 80·정보 30·유물 1·명성 12를 한 번만 받는다.
- 반복 활동은 완료 횟수를 저장하므로, 전투 임무 사이에도 플레이어의 장기 운영 기록이 남는다.
- 일일 지휘는 전투의 보조 메뉴가 아니라 조장단의 관계, 본부 경제, 세력 평판, 장비 성장을 잇는 두 번째 핵심 루프다.

### 사용자 피드백과 복구

- 지휘 덱 HUD는 날짜, 남은 행동, 네 종류의 자원, 가장 가까운 권장 목표를 모든 운영 화면에서 유지한다.
- **전역 명령:** 첫 훈련, 균형 지휘, 첫 생환, 현장 활동, 유대, 제작을 6개의 장기 목표로 제시한다. 달성 즉시 HUD의 다음 행동이 보상 수령으로 바뀌며, 보상은 한 번만 지급된다.
- 작전실은 출격 인원·평균 레벨·회복동 수준을 합산한 준비도를 보여주되, 플레이어의 출격을 강제로 막지는 않는다.
- 전투는 행동 후 다음 미행동 조장으로 자동 이동하며, 같은 라운드 안에서는 직전 행동을 취소할 수 있다.
- 일일 세 목표를 모두 달성했다면 보상을 받기 전에는 날짜를 넘길 수 없어 획득물을 실수로 놓치지 않는다.
- 재도전은 자원과 경험치를 중복 지급하지 않지만, 이전보다 높은 임무 등급은 저장한다.
- 훈련·관계·현장·제작·시설·전투 결과는 짧은 화면 알림으로 즉시 확인할 수 있다.

### 난이도와 조작 경험

- **기록:** 지휘점 4, 강화된 보호 목표, 약화된 적으로 서사와 캐릭터 선택을 우선한다. 기본 보상은 유지한다.
- **정규:** 원래 전장 수치와 보상을 사용하는 권장 경험이다.
- **생환:** 적 생명과 공격력이 증가한다. 첫 클리어 보급·정보·명성이 25% 증가하고 유물 1개를 추가 지급한다.
- 난이도는 임무마다 선택하며 저장 데이터의 영구 옵션으로 고정하지 않는다. 플레이어는 막힌 임무만 기록 난이도로 전환할 수 있다.
- 모바일에서는 전장을 우선 노출하고 기술·기록·턴 종료를 하단 전술 명령 패널에 넣는다. 기술 선택 뒤 패널은 자동으로 닫혀 표적을 즉시 고를 수 있다.
- 작전 포기는 첫 입력에 확인 상태로 바뀌며 짧은 시간 안에 다시 눌러야 실행된다. 잘못된 터치로 전투를 잃지 않게 한다.
- 모든 주요 메뉴는 의미 있는 버튼과 포커스 표시를 사용하며, 현재 화면은 `aria-current`로 전달한다.

## 7. 전투 확장 원칙

- 체능은 캐릭터의 스킬 세트가 아니라 삶의 방식과 연결한다.
- `극치`는 반복 가능한 숙련, `극의`는 미래와 신체를 당겨 쓰는 영구 희생으로 분리한다.
- 해찬의 극의는 플레이어가 따라 해야 할 최적해가 아니라, 라온이 끝내 극복해야 할 선대의 해답이다.
- 권능은 A.S. 0 이후 소멸했으므로 현재편 전투에 편의적으로 복귀시키지 않는다.
- 총기는 체능의 하위 무기가 아니라 권능을 잃은 체시가 선택한 새로운 전쟁 방식이다.

## 8. 캠페인 로드맵

### 제7기 전반

- 입단 예비과정과 조장 선발전
- 〈회수보다 구조〉: 신성 주입 시설 기록과 생존자 중 무엇을 먼저 택할지 결정
- 〈시티즌의 탄피〉: 크리스·테나와 구세계 밀수망 추적
- 〈비어 있는 기수의 마을〉: 제3기 생존자와 아델린의 기록
- 〈날개 없는 호송〉: 실험체 지원자 보호
- 〈하늘의 총성〉: 해찬을 아는 체시 저격수와 충돌

### 해찬편

- 아직 군단이 아니었던 생존자들의 만남
- 여섯 깃발과 첫 공동작전
- 반란군의 전성기, 일상, 관계 개그
- 라미의 소거 계획과 세 갈래 분열
- 해찬의 극의, 불완전한 빛, 모든 권능의 소멸

### 제7기 후반

- 해찬의 귀환과 진훤의 역사 삭제 심판
- 가람 세력, 체시 화기군, 제국의 삼중 충돌
- 나비의 폭주와 제6기의 배신
- 라온류·카즈린류 완성, 하도리의 나비류 본류 계승
- 진훤 사후 레오가 프시케의 중심을 이어받음

## 9. 기술 구조

- React/Vite 화면 계층과 순수 TypeScript 전투 엔진을 분리한다.
- 전투 엔진은 React 상태에 의존하지 않아 단위 테스트와 향후 세이브 재현이 가능하다.
- 정사 원문은 `docs/source`에 보존하고, 게임용으로 선별한 데이터만 `src/data`에서 명시적으로 관리한다.
- 장기적으로 임무·대사·도감 데이터는 `public/content` 구조와 연결해 콘텐츠 빌드 파이프라인으로 이전한다.
