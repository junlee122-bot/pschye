# 《라온제나》 장소 비주얼 바이블

## 목적

프시케 세계의 장소를 배경 설명용 정지 이미지가 아니라, 라온의 선택과 전투·관계·기억이 실제로 발생하는 게임 공간으로 관리한다.

현재 정사 대서사는 86개 에피소드와 85개 고유 장소로 구성된다. 모든 에피소드는 하나의 장소에 다음 11개 제작 에셋을 가진다.

| 에셋 | 역할 |
|---|---|
| `explore.webp` | 진입, 이동 동선, 랜드마크와 탐험 분위기 |
| `dialogue.webp` | 인물 관계와 선택 대화에 적합한 중경 |
| `battle.webp` | 엄폐, 고저차, 위험 방향이 드러나는 전투 구도 |
| `aftermath.webp` | 선택의 결과와 시간 변화를 보여주는 전후 구도 |
| `thumb.webp` | 지도, 목록, 임무 카드의 저비용 미리보기 |
| `beats/01.webp`~`06.webp` | 에피소드의 여섯 플레이 장면 전용 비주얼 |

총 스토리 장소 비주얼 참조 수는 946개다.

## 8개 권역

1. **변방과 마을** — 라온의 고향, 피난민 도로, 교각, 설원, 생활형 공간
2. **프시케 시설** — 원형장, 숙소, 의무동, 기록보관소, 지하 기억시설
3. **제국 수도** — 황궁, 시민구, 상업구, 성벽, 수로와 전후 재건 구역
4. **저주받은 땅** — 혼혈 도시, 연합촌, 폐도시, 원소 지대
5. **체시 지배권** — 부유요새, 대경기장, 연구소, 수도와 처형 시설
6. **데닌 영지** — 아스텔, 벨루아, 아르카와 멸족당한 가문 영지
7. **전선과 작전지** — 여섯 군단 주둔지, 회담장, 야영지, 전쟁 중심부
8. **기억과 금지구역** — 빛의 분화구, 삭제된 기록층, 집단 기억 경계

권역 대표 환경화는 `public/art/locations`에 저장한다. 대표 환경화는 텍스트 없는 16:9 WebP, 1920px 이하, UI를 얹을 수 있는 좌상단 명암 여백을 기본 규격으로 한다.

## 시각 원칙

- 서양 고딕 판타지와 전후 재건 문명을 공통 기반으로 둔다.
- 체시는 차가운 상아·흑요석·천상 기하학, 데닌은 적색 암벽·진홍 식생·황동 조명을 사용한다.
- 프시케와 제국은 검정·상아·앤티크 골드, 저주받은 땅은 회색·심자색·원소 균열을 사용한다.
- 장소마다 들어갈 수 있는 문, 이어지는 길, 고저차와 엄폐물을 명확히 보여준다.
- “예쁜 배경”보다 플레이어가 다음 행동을 상상할 수 있는 공간을 우선한다.
- 전투 이미지는 적보다 사선·퇴로·민간인 위치가 읽혀야 한다.
- 같은 장소의 전후 이미지는 구조물 손상, 인구, 날씨, 깃발과 조명 변화로 선택의 결과를 보여준다.

## 게임 연결

`src/data/locations.ts`가 에피소드 데이터를 장소 중심으로 재구성한다.

- 같은 장소가 여러 에피소드에 등장하면 하나의 장소 항목에 기억이 겹친다.
- 장소 검색은 이름·권역·등장 인물·주제·시대를 모두 대상으로 한다.
- 각 장소는 네 개 시네마틱 변형과 여섯 장면 이미지를 모두 노출한다.
- Chronicle의 `장소 도감` 탭에서 85개 장소를 직접 탐색한다.
- 실제 파일 누락은 `pnpm assets:audit`와 `src/data/locations.test.ts`가 검출한다.

## 성능 규격

- 권역 대표 아트: 1920px 이하 WebP, 권장 180~350 KiB
- 에피소드 메인 아트: 화면에서 선택된 한 장만 즉시 로드
- 목록 미리보기와 여섯 장면: `loading="lazy"`
- 모바일에서는 장소 목록과 권역 필터를 수평/제한 스크롤로 전환
- 장면 카드가 많아도 전체 원본을 한 번에 화면에 배치하지 않는다.

## 신규 장소 추가 체크리스트

1. `grandStory.ts`에 장소명과 여섯 장면을 추가한다.
2. `public/art/story/scenes/{episodeId}`에 11개 파일을 저장한다.
3. 장소명이 기존과 같다면 동일한 표기를 사용해 기억이 합쳐지게 한다.
4. 새 권역이 필요하지 않다면 `inferWorldLocationCategory` 키워드를 갱신한다.
5. `pnpm assets:audit`, `pnpm test`, `pnpm build`를 실행한다.
6. 장소 도감에서 PC와 모바일 레이아웃을 모두 확인한다.
