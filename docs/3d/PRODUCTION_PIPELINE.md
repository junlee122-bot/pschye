# 라온제나 3D 캐릭터 제작 파이프라인

## 현재 구현

- 48인 전 캐릭터의 실행 가능한 GLB 2.0 절차형 마켓
- 캐릭터당 20개 서사 단계 원화, 총 960개 변형 레퍼런스
- 게임 내 원화/GLB 동시 비교 검수실
- GLB 헤더, JSON/BIN 청크, 메시, 재질, 노드, 삼각형, 경계, 리깅과 애니메이션 상태 자동 감사
- 생산 카탈로그와 교차 검증 하네스

현재 GLB는 **절차형 마켓**이다. 실루엣, 신장, 배색, 무기와 런타임 경로를 빠르게 검토하기 위한 실제 파일이며,
최종 아티스트 모델이나 리깅된 전투 캐릭터라고 표시하지 않는다.

## 원화에서 게임 모델까지

1. **캐논 에이전트** — 설정집과 20단계 원화의 충돌을 검사한다.
2. **실루엣 에이전트** — 플레이 카메라에서 신장, 체형, 무기, 헤어 실루엣을 비교한다.
3. **모델링 에이전트** — Blender에서 LOD0 토폴로지와 UV를 제작한다.
4. **재질 에이전트** — cel-PBR, 피부·눈·머리카락·금속 재질과 외곽선을 조정한다.
5. **리깅 에이전트** — 휴머노이드 본, 무기 소켓, 천 프록시와 표정 셰이프를 구성한다.
6. **애니메이션 에이전트** — 공통 이동 세트와 캐릭터별 체능 동작을 제작한다.
7. **런타임 에이전트** — GLB 압축, LOD, 메모리 예산과 로딩 우선순위를 적용한다.
8. **QA 판정 에이전트** — 자동 지표와 원화 비교 결과를 교차 검증하고 승인/반려한다.

에이전트는 독립적인 평가 기준을 사용한다. 모델 생성자가 자신의 결과를 최종 승인하지 않으며, 캐논·기술·가독성
세 판정이 모두 통과한 산출물만 `production`으로 승격한다.

## 품질 단계

| 단계 | 목적 | 현재 상태 |
|---|---|---|
| 절차형 마켓 | 전 캐릭터 실루엣·배색·경로 검증 | 48/48 완료 |
| 아티스트 LOD0 | 의상 구조, 얼굴, 헤어 카드, 장비 | 제작 대기 |
| 리깅·표정 | 78본 휴머노이드, 표정 52종+보정 | 제작 대기 |
| 전투 애니메이션 | 공통 12종, 고유 전투 5종 이상 | 제작 대기 |
| LOD/모바일 | LOD1 55%, LOD2 22%, 메모리 검증 | 제작 대기 |

## 캐릭터당 20단계

`public/data/model-production-catalog.json`이 48인 전원의 20단계 레퍼런스를 추적한다.
핵심 다섯 단계(선택 이전, 입단, 현장, 대전쟁, 현재)는 독립 의상/신체 변형으로 제작하고, 나머지는 공용 베이스 위
모듈식 의상·상처·장비 변형으로 구성한다.

## 자동 검증

```bash
pnpm models:generate
pnpm models:catalog
pnpm models:audit
pnpm models:harness
pnpm models:refine
```

`models:harness`는 다음을 독립 검증한다.

- 48인 런타임 모델과 생산 원장의 일대일 대응
- 캐릭터당 최소 20개 원화 변형
- GLB 바이너리 무결성
- 캐릭터별 최소 7개 생산 승인 게이트
- 리깅·애니메이션 미완료 모델의 경고 유지

## Blender 승격 규칙

Blender가 설치된 제작 환경에서는 GLB 2.0으로 내보내며, Y-up과 미터 단위를 유지한다. 각 파일은 `LOD0`, `LOD1`,
`LOD2`, `COLLIDER`, `SOCKET_*` 명명 규칙을 사용한다. 절차형 마켓 경로는 유지하고 생산 카탈로그의 런타임 경로만
승인된 모델로 바꿔 게임 코드를 수정하지 않고 교체한다.
