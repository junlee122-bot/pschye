# 라온제나 캐릭터 제시 시스템

## 목표

캐릭터 설정집 이미지를 그대로 대화창에 축소해 넣지 않고, 역할에 따라 분리한다.

- **대화 장면:** 큰 초상, 시선 거리, 감정의 지속, 화자 우선순위
- **설정화 보기:** 사용자가 만든 시대별 카드와 원본 설정을 온전히 열람
- **도감:** 세대·진실·관계·20단계 성장 기록을 수집하는 화면
- **전투:** 얼굴 식별성이 높은 정사각 초상과 실루엣

## 참고한 장르 원칙

- `Pentiment`: 세계관의 미술 양식을 UI 전체의 문법으로 사용하고, 인물과 공동체의 변화가 장기간 누적된다.
- `Citizen Sleeper`: 적은 수의 강한 인물 일러스트와 텍스트를 결합해 독자의 상상 공간을 남긴다.
- `Baldur's Gate 3`: 선택지를 고르는 동안에도 인물이 감정을 유지하고, 주변 동료도 장면에 반응한다.
- `Life is Strange`: 플레이어가 한 주인공의 관점에 머물며 관계와 선택을 체험한다.

## 라온제나 적용 원칙

1. 라온은 모든 대화의 시각적 기준점이다.
2. 현재 화자는 더 크게, 더 선명하게 보여준다.
3. 친밀·균형·대립 카메라를 장면 성격에 따라 교체한다.
4. 감정은 `warm`, `guarded`, `focused`, `uneasy`, `resolved` 다섯 단계로 지속한다.
5. 20종 시대별 카드는 본편을 가리지 않도록 선택형 설정화 보기에서 제공한다.
6. 모바일에서는 화자를 크게 유지하고 라온은 작은 관점 앵커로 축소한다.
7. 모션 감소 설정에서는 입장·오버레이 애니메이션을 제거한다.

## 에셋 사용 규칙

- `/art/portraits/*`: 본편 대화·전투용
- `/art/characters/{id}/01-20*.webp`: 성장 기록·시점 설정화
- `/art/archive/*`: 도감과 역사 기록
- `/art/story/*`: 장면 배경

이 구분을 유지하면 설정집의 밀도와 스토리 화면의 가독성을 동시에 확보할 수 있다.
