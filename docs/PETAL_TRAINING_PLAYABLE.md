# 열여섯 꽃잎 수련 플레이 구간

작성 기준: 2026-09-15. 자동검사와 실제 화면 확인의 범위를 구분해 기록한다.

## 원전과 각색 경계

[원전 v3.1](source/world-bible-v3.1.md) §53·76~78·150의 인과를 따른다. 라온은 체능 기본기와 지구력이 부족해 활동 보류 뒤 마루를 찾는다. 마루는 **기를 싣지 않은 몸짓·손가락·나뭇가지·말과 기억**으로 동작과 원리를 전하며, 라온이 자기 몸과 감각으로 이를 재구축한다. 완성된 기술의 전수, 마루와의 능력 대련, 기의 주입으로 표현하지 않는다. 마루의 계약 해제·키티 예외·과거의 비밀을 수련 보상으로 공개하지 않는다.

기존 `originStory.ts`의 `sixteen-petals`는 선발 17~29일, 연구소 뒤편 폐정원의 수련 몽타주다. 이번 입력·턴·부담 수치는 그중 반복과 조정을 표현하는 **게임 각색**이며 실제 보법 교본이나 원전의 물리 법칙이 아니다. 재시도 횟수를 날짜·신체 손상·선발 탈락으로 환산하지 않는다. 카즈린이 약과 붕대를 남긴 기존 장면을 넘어 동료 전원이 수련장에 참여했다고 덧붙이지 않는다.

§87의 라온류는 장기 성장이다. 무게를 나누는 선택은 첫 단서이며 자멸 구조를 이미 해결하거나 전성기 해찬을 넘어선 완성으로 쓰지 않는다. 결의의 무리도 극의·권능·영구 장애의 획득이 아니다. 수련 완료는 **열여섯 궤적을 한 번 이어 본 성취**다.

## 선택과 행동

선택별 문구는 `src/data/petalTraining.ts`의 `petalTrainingApproaches`를 사용한다. `pending`은 시도할 방침만 말하고, `completion`은 마루 앞 마무리를 확인한 뒤에만 표시한다.

| 기존 선택 | 이번 수련의 차이 | 유지하는 의미 |
|---|---|---|
| `remember-voices` · 연민 | 호흡 고르기의 부담 감소가 4다. | 기억한 사람의 호흡과 움직일 간격에 흐름을 맞춘다. |
| `distribute-weight` · 통찰 | 무게 나누기로 궤적 3개를 잇고 부담 1이 늘어난다. | 다리에 몰리는 부담을 나눌 첫 원리를 찾는다. |
| `step-beyond-fall` · 결의 | 보법 이어가기로 궤적 5개를 잇고 부담 3이 늘어난다. | 한 번 더 잇는 추진력과 무리의 위험을 함께 다룬다. |

기본 행동은 보법 이어가기(`trace`: 궤적 `+3`, 부담 `+2`), 무게 나누기(`balance`: `+2`, `+1`), 호흡 고르기(`breathe`: 부담 `-3`)다. 위 선택별 차이만 대체 적용한다. 부담이 0이면 호흡 고르기는 선택할 수 없다. 유효한 입력마다 한 턴이 흐르며, 화면을 읽거나 자리를 비운 시간은 진행시키지 않는다.

목표는 궤적 16개, 부담 한계는 8, 최대 10턴이다. **부담 8 도달은 16개 달성보다 먼저 실패로 판정**한다. 10번째 유효 행동에서도 궤적 16개와 부담 8 미만이면 `review`에 도달할 수 있다. 한계 미만의 몸 상태로 16개를 잇는 것과 수련을 확정하는 것은 별개이며, `review`에서 ‘마루 앞에서 마무리’ 확인 뒤 `complete`가 된다.

## 상태·저장·후속 장면

상태는 `ready → active → review → complete`, 중단 시 `active → failed → active`(명시적 재시도)다. `originStory.petalTraining`은 선택 ID, 시도, 턴, 궤적 수, 부담, 단계, 현장 기록을 보존한다. 중단은 같은 방침으로 다시 조정할 수 있는 게임 상태이며, 죽음·영구 부상·체능 상실을 결과로 확정하지 않는다. 불가능한 행동·중복 입력·이전 시도의 늦은 입력으로 진행이나 보상이 늘지 않아야 한다.

선택할 때 기존 성향 `+1`, 평가 점수 `6 / 7 / 7`, 마루 관계 `+2`를 의도로 한 번 기록한다. 기존 완료 플래그와 NPC의 `choice.result`만 `complete`까지 지연한다. 재시도·호흡·마무리로 XP·스킬 포인트·영구 능력치를 주지 않는다. 본편 `sixteen-petals`의 피해·사기, `unfinished-flow`, 장비·성장 수치를 이 수련에 가져오거나 변경하지 않는다.

선택만 한 구버전 저장은 선택과 이미 받은 수치를 유지하고 수련 준비로 이어간다. 미리 기록된 완료 사실은 실제 마무리까지 보류한다. 이미 `sixteen-petals`를 마쳤거나 후속 장면·서장 완료에 도달한 저장은 재수련을 강요하지 않는다. 저장 필드 추가는 기존 저장과 호환되도록 선택 필드로 다룬다.

마무리 뒤 기존 `captain-trials`로 이어진다. §78의 카인·카즈린 상대 승리, 하도리에게 패배, 라온 제2조장과 여섯 명의 입단 인과는 성적·턴·선택으로 바뀌지 않는다. 이 구간에서 선발 결과를 먼저 확정하거나 정식 전투 보상을 지급하지 않는다.

## 자동검사

`src/components/PetalTrainingEncounter.test.tsx`의 SSR 8개 테스트와 소유 데이터·테스트 파일 ESLint를 통과했다. 준비 단계의 선택 안내, 부담 0 호흡 금지, 마루 확인 전 결과·진행 버튼 비노출, 궤적 16·부담 8 동시 도달 시 실패 안내, 타이틀 단계 요약, 미완료 회고 비노출과 완료 구세이브 후속 장면을 확인했다. 이는 화면의 정적 출력 검사이며 실제 클릭·초점 이동·브라우저 저장 검사는 아니다.

- [x] 세 선택의 행동 차이, 부담 0의 호흡 금지, 범위 밖·단계 밖·이전 시도 입력을 검사했다.
- [x] 부담 한계 우선, 10번째 턴 성공, 시간 초과 중단과 명시적 재시도를 검사했다.
- [x] 선택 수치 1회 유지, `review`와 `complete` 구분, 완료 사실 지연과 반복 확인의 중복 지급 방지를 검사했다.
- [x] 각 단계·매 행동 뒤 저장/로드, 모순된 저장값 거부, 구버전 선택만 한 저장과 이미 완료한 저장의 호환을 검사했다.
- [x] SSR에서 완료 전 결과 비노출, 단계별 버튼과 행동 금지, 타이틀 이어하기, 회고의 완료 전 비노출을 검사한다.

전체 22개 파일의 312개 테스트와 TypeScript·ESLint 검사가 통과했다. 수련 규칙 25개, 화면 SSR 8개, 저장 손상 사례 1개가 추가됐다. 세 선택의 모든 도달 가능한 규칙 상태에서 동작 실행과 저장 유효성이 일치함을 검사했고, 수로·폐광·수련 상태가 함께 남는 저장도 확인했다.
