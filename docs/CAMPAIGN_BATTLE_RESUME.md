# 정식 작전 저장·재개 계약

2026-09-14 · 네 번째 작업 묶음

입단 후 첫 정식 작전부터 출전·중단·재개·결과 정산을 하나의 저장 기록으로 연결한다. 선발 시험의 새 플레이 구간과 원전 설정 추가는 이번 범위에 포함하지 않는다.

## 출전과 저장

- 입단 완료, 알려진 임무와 선행 임무 완료, 해당 임무의 유효한 이야기 선택, 라온을 포함한 4~6명 편성을 확인하고 출전한다.
- `CampaignProfile.battleAttempt`에 시도 ID, 임무, 난도, 교리, 라온 선택, 전쟁 압박, 현장 신뢰, 성장·장비를 적용한 출격조 정보를 고정한다. 대기 중 편성과 장비를 변경해도 저장된 전투의 능력치는 바뀌지 않는다.
- 전투 방식 선택 전부터 기록을 만든다. 전술 지휘는 행동·턴·선택 기술과 최대 8개 행동 취소 기록을 저장한다.
- 액션은 실제 진행 시간, 위치·방향, 생명·목표 내구·방벽, 자세·연격·사기, 아군 상태, 동료 명령 대기, 적 위치·생명·자세·공격 예고·기절을 저장한다. 타이머는 남은 밀리초이며 실제 시각을 저장하지 않는다.
- 액션 체크포인트는 약 1초 간격과 명령·승패·일시정지·나가기 시 갱신된다. 브라우저 저장 실패는 기존 저장 실패 안내와 다시 저장 동선을 따른다. 강제 종료 시 마지막으로 저장된 체크포인트 이후의 입력은 복구할 수 없다.
- 액션 재개 안내를 닫기 전에는 시간이 흐르지 않는다. 수동 일시정지와 배경 탭 전환도 같은 재개 절차를 사용한다. 장식용 타격 섬광·카메라 흔들림은 재연하지 않으며, 미완료 적 공격 예고는 남은 시간으로 복원한다.

## 결과와 다시 시도

- 같은 시도의 저장된 승리 상태만 정산한다. 진행 중 상태, 패배, 다른 임무 결과, 재시도 전의 오래된 콜백은 보상을 지급하지 않는다.
- 승리 체크포인트를 먼저 반영하고 보상과 `settled`를 한 프로필 갱신에서 적용한다. 승리만 저장된 뒤 종료되면 다음 로드 때 정산을 복구한다.
- 자원 보상은 공통 프로필에, 경험치는 실제 출격조에 지급한다. 재현 작전은 기존 규칙대로 추가 자원·경험치 없이 등급과 유효한 목격 기록만 갱신한다.
- 다시 시도와 전투 방식 전환은 새 시도 ID를 사용하고 고정된 출전 조건으로 처음부터 시작한다. 전투 방식 전환에는 초기화 확인이 있다.
- 미정산 전투가 있으면 새 출전을 막는다. 타이틀과 작전실에서 이어가거나, 작전실에서 저장된 전투 정리를 확인한 후 다시 준비할 수 있다. 정리는 이미 받은 보상과 이야기 선택을 지우지 않는다.
- 정산된 결과를 보관한 상태에서 같은 임무의 이야기 선택을 바꾸면 이전 결과 카드만 정리한다. 이미 얻은 보상·등급·목격 기록은 유지하고, 바뀐 선택은 새 출전에 적용한다.
- 슬롯 전환·새 여정은 이전 화면의 콜백 세대를 무효화한다. 전투 화면의 나가기 버튼으로 마지막 상태를 전달한 뒤 작전실로 돌아간다.

## 호환성과 검증 경계

- 저장 키·버전 v10을 유지한다. 전투 기록이 없는 기존 저장은 그대로 읽는다.
- 선택적 전투 기록이 있으면 구조·수치·임무·편성·방식·결과를 검증한다. 손상된 기록은 기존 로컬/백업 복구 절차에 맡기고 빈 진행으로 덮어쓰지 않는다.
- 단일 완료 플래그만 있던 과거 저장의 마이그레이션은 내부 전용 경로를 사용한다. 공개 임무 완료 함수는 실제 유효한 승리 상태를 요구한다.
- 로컬 저장의 구조 검증이며 서버 기반 부정행위 방지 기능은 아니다.
- 전술 전투 로그 ID는 저장된 로그의 최대 ID 다음에서 이어간다. 목표 파괴·아군 전멸이 적 전멸과 동시에 발생하면 패배를 우선한다.

## 검증 체크리스트

자동 검증: 출전 조건, 출전 정보 고정, JSON 왕복, 액션 타이머 재기준화, 잘못된 기록 거부, 재시도와 오래된 콜백, 정산 복구·중복 방지, 실제 출격조 보상, 기존 저장 호환.

실제 화면에서 별도로 확인할 항목:

1. 타이틀의 저장된 작전 이어가기와 작전실의 진행 정리.
2. 전술 명령 후 나가기·새로고침·재개, 행동 취소까지 이전 상태 유지.
3. 액션 이동·동료 명령 후 일시정지·나가기·재개, 위치와 남은 대기 시간 유지.
4. 승리 결과 재접속과 작전실 복귀 후 보상 중복 없음.
5. 390px 화면에서 재개 버튼·저장 안내 접근, 슬롯 변경과 새 여정 뒤 이전 결과 미반영.

자동 검사 통과를 실제 플레이 완주로 간주하지 않는다. 이번 실행에서 확인한 화면과 미확인 항목은 별도 완료보고서·브라우저 기록에 남긴다.
