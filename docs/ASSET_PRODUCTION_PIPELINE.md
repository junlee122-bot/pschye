# 라온제나 자산 제작 파이프라인

MengTo/Skills의 핵심인 **실제 파일과 선언만 존재하는 자산을 분리하고, 재현 가능한 검수 절차를 게임 제작 과정에 고정하는 방식**을 라온제나의 2D 에셋 구조에 맞게 구현했다.

## 1. 단일 자산 원장

`tools/asset-ledger-audit.mjs`는 `public/art`의 실제 배포 파일을 전수 조사한다.

- 런타임 경로와 정적 참조 위치
- 픽셀 해상도와 알파 채널
- 파일 용량과 표현 형식
- SHA-256과 동일 파일 중복 수
- 제공 원본·생성 캐릭터·생성 장소·프로젝트 자산의 출처 분류
- 인물·장소·스토리·마을·설정화 카테고리와 변형명
- 해상도·용량·출처·중복 품질 게이트

전체 제작용 원장은 `artifacts/asset-ledger/ledger.json`에 저장한다. 게임이 읽는 `public/data/asset-catalog.json`에서는 제작자의 로컬 원본 경로를 제거한다.

## 2. 품질 게이트

카테고리별 최소 해상도를 다르게 적용한다.

- 캐릭터·초상: 최소 512×512
- 장소·마을·임무·주요 스토리 장면: 최소 1280×720
- 스토리 비트: 최소 960×540
- 스토리 썸네일: 최소 320×180
- 제공 설정화: 최소 900×1200

`pnpm assets:quality`은 교체가 필요한 실패 자산이 하나라도 있으면 종료 코드 1을 반환한다. 출처 프롬프트·모델·시드가 아직 명시되지 않은 생성 자산은 삭제 대상이 아니라 `검토 필요`로 분리해 다음 제작 패스의 우선순위로 사용한다.

## 3. 게임 내 자산 검수실

인물 도감의 `자산 검수실`은 제작 원장을 게임 안에서 직접 읽는다.

- 2,103개 실제 배포 자산과 총 용량 요약
- 품질 통과·검토 필요·교체 권장 필터
- 인물·장소·장면·파일 경로 검색
- 실제 런타임 이미지와 변형 묶음 비교
- 해상도·용량·출처·중복·SHA-256 확인
- 데스크톱 고정 검사 패널과 모바일 단일 열 레이아웃

이 화면의 목적은 많은 이미지를 전시하는 것이 아니라, **게임에서 실제로 읽히는 파일만을 기준으로 누락·중복·저해상도·출처 공백을 발견하는 제작 도구**가 되는 것이다.

## 4. 반복 작업 명령

```bash
pnpm assets:ledger
pnpm assets:ledger:check
pnpm assets:quality
pnpm lint
pnpm test
pnpm build
```

새 캐릭터 변형이나 장소 에셋을 추가할 때마다 위 순서로 원장을 재생성하고 품질 게이트를 통과시킨다.
